# TaskbarSearchText

A lightweight Windows 10 utility for customizing the taskbar search box text.

## Features

* ✨ Custom search box text
* 💾 Automatic backup & restore
* 🕘 History (10 entries)
* ✅ Verify before applying
* 🔄 Graceful Explorer restart

## Build

```bash
dotnet build -c Release
```
